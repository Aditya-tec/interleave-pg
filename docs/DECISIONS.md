> **Historical note (the only place the old name is explained):** until Gate G1 this project was developed under the working name `raceproof` (env vars `RACEPROOF_*`, database prefix `raceproof_`, marker table `raceproof_marker`). It was renamed to `interleave-pg` in one commit because several unrelated GitHub projects already use "RaceProof" (see COMPETITORS.md). `docs/phase-1-report.md` records the Phase 1 evidence runs and keeps the old names exactly as they were typed at the time.
| 2026-10-27 | **deadlock_timeout is 300 ms (was 50 ms).** `init-db` and `doctor` updated; the init-db test expects 300ms | A forced-schedule test showed the deadlock victim is not stable at 50 ms: Postgres aborts the waiter whose timer fires first once a cycle exists, and when the second statement starts waiting more than ~50 ms after the first (CPU load), the second waiter becomes the victim. The victim decides which statements run next, so it changes timelines and replay fingerprints. AC1.4 (40P01 within 2 s) still holds | Keeping 50 ms and tolerating flaky timelines; making the engine cancel a backend itself (would produce 57014, not 40P01) |
